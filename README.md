# KarachiGum.com | Premium Industrial Guar Gum Supplier

Official repository for **KarachiGum.com**, global leaders in industrial chemical supply. Providing premium quality Guar Gum and industrial solutions worldwide.

## 🚀 Live Repository
[View on GitHub](https://github.com/syed-mujtaba-stack/KarachiGum.com)

## 🛠️ Features
- **Industrial Design**: High-end B2B aesthetic with "Industrial Aura" effects.
- **AI Integration**: Custom ChatGPT-style assistant for technical queries.
- **Micro-services**: Laboratory initialization loading system and technical error states.

## 🏁 Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 🏗️ Tech Stack
- **Next.js 15** (App Router)
- **Tailwind CSS v4**
- **Lucide React** (Industrial Icons)
- **OpenRouter AI**

## 📦 Deployment
The easiest way to deploy is via [Vercel](https://vercel.com/new).
