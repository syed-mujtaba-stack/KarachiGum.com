# Security Policy

## Reporting a Vulnerability

We take the security of KarachiGum.com seriously. If you believe you have found a security vulnerability, please report it to us responsibly.

Please do not open a public issue for security vulnerabilities. Instead, please email technical@karachigum.com (placeholder) with the details of the vulnerability.

We will acknowledge your report within 48 hours and provide a timeline for a fix.
